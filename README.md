# Smith Heating & Air Conditioning Website Concept

Standalone local outreach preview shaped around the company’s published services and identity.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Project notes

- Prospect site: https://smithheatingandair.com/
- The hero uses the family photo supplied for this Smith project. The navbar and favicon use the original Smith logo image supplied by the user.
- Company details, contact information, theme, and service areas are in `src/config/site.config.ts`; confirm details before any launch.
- The contact form is a preview and does not send submissions. Map tiles need an internet connection; map coverage is representative.
